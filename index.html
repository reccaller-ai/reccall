🔌 Plugin Architecture

RecCall's universal AI context engine uses a modular plugin architecture with dependency injection, making it easy to extend and integrate with any AI tool or platform.

🏗️ Core Engine

Centralized business logic with dependency injection

  • IContextStorage - CRUD operations
  • IRepositoryClient - Remote repository management
  • ICacheManager - Multi-layer caching
  • IRecipeValidator - Security validation
  • TelemetryManager - Performance monitoring

🔌 Platform Adapters

Thin wrappers around core engine for different platforms

  • CLI Adapter - Command-line interface
  • MCP Adapter - Model Context Protocol server
  • VSCodeAdapter - VSCode extension with core engine
  • Warp Integration - Terminal shell via CLI (uses core engine)
  • Browser Extensions - Web platform support
  • All platforms use unified core engine - Consistent features across all integrations

Creating Dynamic Contexts from Conversations

// Example: Create dynamic context from conversation import { ContextEngine } from 'reccall/core'; const engine = new ContextEngine(); await engine.initialize(); // Sample conversation (from test cases) const messages = [ { role: 'user', content: 'How do I test this?', timestamp: new Date() }, { role: 'assistant', content: 'You can use unit tests with vitest.', timestamp: new Date() } ]; // ML processing happens automatically const context = await engine.createFromConversation({ name: 'testing-guidelines', messages, source: 'local', tags: ['testing', 'unit-tests'] }); console.log(context); // Output: { id: "ctx_k2m9x7p4", name: "testing-guidelines", type: "dynamic", content: "# Discussion about: How do I test this?\n\n## Key Points\n- How do I test this?\n\n## Code References\n\n## Details\nUser: How do I test this?\n\nAssistant: You can use unit tests...", ml: { embedding: [0.0234, 0.0156, ...], // 384 dimensions summary: "Discussion about: testing, unit. How do I test this?", topics: ["testing", "unit"], codeRefs: [] }, tags: ["testing", "unit-tests"], usageCount: 0 }

Enhancing Static Templates with ML Insights

// Example: Hybrid context creation // First, create a static template const template = await engine.createStatic({ name: 'code-review-template', content: '# Code Review Guidelines\n\n1. Check for security issues\n2. Verify error handling', source: 'global', tags: ['review', 'guidelines'] }); // Then enhance it with conversation insights const hybrid = await engine.enhanceContext({ name: 'enhanced-review', templateName: 'code-review-template', messages: [ { role: 'user', content: 'Found a SQL injection vulnerability in user.js', timestamp: new Date() }, { role: 'assistant', content: 'Here\'s how to fix it using parameterized queries...', timestamp: new Date() } ], source: 'local' }); // Enhanced context includes: // - Original template content // - ML-generated summary // - Extracted topics // - Code references from conversation // - Semantic embedding for search

Hybrid Search Example

// Example: Hybrid search (keyword + semantic) // Create contexts with different content await engine.createStatic({ name: 'api-testing', content: 'API testing guidelines and best practices', source: 'local', tags: ['api', 'testing'] }); await engine.createStatic({ name: 'endpoint-validation', content: 'How to validate REST API endpoints', source: 'local', tags: ['api', 'validation'] }); // Search combines keyword and semantic matching const results = await engine.search('API testing'); // Returns both 'api-testing' (keyword match) // and 'endpoint-validation' (semantic similarity) console.log(results.length); // 2 console.log(results[0].name); // 'api-testing' console.log(results[1].name); // 'endpoint-validation'
