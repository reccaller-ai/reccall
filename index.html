🚀 Quick Start

Deploy RecCall across your organization with a single command. Automatic configuration, security features, and scalable architecture.

# Installation curl -sfL https://reccaller.ai/install.sh | sh - # Configure Repository reccall repo-config --set-repo https://reccaller-recipes.io # Install Recipes reccall install sync-main reccall install create-feature-branch reccall install create-pr

Repository Configuration Examples

🏗️ RecCall System Architecture

RecCall is built with a modular, extensible architecture that supports both local and remote recipe management with seamless IDE integration.

🖥️ Client Layer

Multi-platform client implementations for different development environments

  • CLI Tool (Node.js/TypeScript)
  • Cursor IDE MCP Server
  • VSCode Extension
  • Warp Terminal Integration
  • Shell Script Integration

📦 Core Engine

Central recipe management and execution engine

  • Recipe Storage & Retrieval
  • Context Processing
  • Command Execution
  • Cache Management
  • Validation & Security

🌐 Repository Layer

Remote and local repository management system

  • HTTP/HTTPS Repository Client
  • Local File System Storage
  • Recipe Caching & TTL
  • Manifest Processing
  • Version Management

🔧 Integration Layer

Platform-specific integrations and adapters

  • Git Workflow Integration
  • IDE Communication Protocols
  • Terminal Shell Integration
  • File System Operations
  • Network Operations

Data Flow Architecture

# RecCall Data Flow User Command → CLI Parser → Recipe Resolver → Context Processor → Command Executor # Repository Flow Repository URL → HTTP Client → Manifest Fetch → Recipe Download → Local Cache → Recipe Execution # IDE Integration Flow IDE Request → MCP Server → Recipe Lookup → Context Processing → Response → IDE Display

📋 Repository Schema & Structure

RecCall repositories follow a standardized schema for consistent recipe management and discovery across different hosting platforms.

Repository Structure

# Standard Repository Layout repository-root/ ├── manifest.json # Repository metadata and recipe index ├── recipes/ # Individual recipe files │ ├── git-workflow.json │ ├── deployment.json │ └── testing.json └── README.md # Repository documentation

Manifest Schema

# manifest.json Structure { "name": "Repository Name", "description": "Repository description", "version": "1.0.0", "author": "Repository author", "url": "https://reccaller-recipes.io", "recipes": [ { "name": "Recipe Display Name", "shortcut": "recipe-shortcut", "description": "Recipe description", "file": "recipes/recipe1.json", "category": "development", "tags": ["git", "branch", "feature"], "version": "1.0.0" } ] }

Recipe Schema

# Individual Recipe File Structure { "shortcut": "recipe-shortcut", "context": "The actual context/instruction content", "name": "Recipe Display Name", "description": "Recipe description", "category": "development", "tags": ["git", "branch", "feature"], "version": "1.0.0", "author": "Recipe author", "created": "2024-01-01T00:00:00Z", "updated": "2024-01-01T00:00:00Z" }

⚙️ Technical Specifications

Detailed technical specifications for RecCall's implementation and integration capabilities.

🔧 CLI Specifications

  • Node.js/TypeScript implementation
  • Commander.js for command parsing
  • Cross-platform compatibility
  • Configurable repository URLs
  • Local caching with TTL support

🌐 Repository Protocol

  • HTTP/HTTPS repository access
  • JSON manifest format
  • Static file hosting support
  • Cache-first strategy
  • Version-based updates

🔌 IDE Integration

  • MCP (Model Context Protocol) server
  • VSCode extension API
  • Terminal shell integration
  • Real-time context processing
  • Cross-platform compatibility

💾 Storage & Caching

  • Local file system storage
  • JSON-based recipe format
  • Configurable cache TTL
  • Incremental updates
  • Offline capability

API Endpoints & Commands

# Repository Commands reccall search # Search recipes in repository reccall install # Install recipe from repository reccall remove # Remove installed recipe reccall list-repo # List available repository recipes reccall repo-config # Configure repository settings reccall repo-cache-clear # Clear repository cache # Local Commands reccall list # List installed recipes reccall call # Execute recipe reccall delete # Delete recipe reccall search-local # Search local recipes
