Sora Integration

Enhance Sora AI with persistent context and knowledge management

Overview

RecCall integrates with Sora AI to provide persistent context and knowledge management for AI-powered code generation and assistance. Your project standards, architectural decisions, and coding patterns are automatically available in every Sora interaction.

✨ Key Benefits

  • Code Generation Context: Sora generates code that follows your project's patterns and standards
  • Architecture Awareness: Generated code considers your system architecture and dependencies
  • Consistent Style: Maintain coding style consistency across all AI-generated code
  • Knowledge Persistence: Project knowledge persists across sessions and conversations

How to Integrate

1

Install RecCall

First, ensure RecCall is installed globally:

npm install -g reccall

Or use the automated installer:

curl -sfL https://reccaller.ai/install.sh | sh -
2

Configure Sora MCP Server

Sora supports Model Context Protocol (MCP). Configure RecCall as an MCP server:

{ "mcpServers": { "reccall": { "command": "reccall-mcp", "args": [], "env": { "RECCALL_STORAGE_PATH": "$HOME/.reccall/contexts" } } } }

Location: Add this configuration to your Sora MCP settings file (typically ~/.sora/mcp.json or similar based on your Sora installation).

3

Create Project Contexts

Create contexts that define your project's standards and patterns:

# Create coding standards context reccall context create "typescript-standards" \ --content "Use TypeScript strict mode. Prefer interfaces over types. Use readonly for immutable properties. Always define return types explicitly." \ --tags typescript,standards,code-style # Create API design context reccall context create "api-design" \ --content "Follow RESTful principles. Use proper HTTP status codes. Implement pagination for list endpoints. Include request/response validation." \ --tags api,rest,design-patterns # Create from conversation (learns from past interactions) reccall context from-conversation "auth-patterns" \ --messages auth-conversation.json \ --tags authentication,security
4

Use in Sora

Once configured, your contexts are automatically available in Sora:

  • Automatic Context Injection: Relevant contexts are automatically included in Sora queries
  • Context-Aware Generation: Code generation considers your stored contexts and patterns
  • Semantic Search: Sora can search your contexts to find relevant patterns and examples
  • Dynamic Context Updates: Contexts can be created from Sora conversations automatically
# In Sora, you can request: "Generate a React component following my typescript-standards context" # Or: "Create an authentication endpoint using my auth-patterns context" # Contexts are automatically applied to improve code quality

Available MCP Tools

RecCall exposes the following MCP tools to Sora for context management:

rec_context_create

Create a new static context

{ "name": "context-name", "content": "Context content", "tags": ["tag1", "tag2"], "category": "development" }

rec_context_get

Retrieve a context by name or ID

{ "identifier": "context-name-or-id" }

rec_context_search

Hybrid search (keyword + semantic) for finding relevant contexts

{ "query": "authentication patterns", "limit": 10, "filters": { "tags": ["security"], "category": "development" } }

rec_context_from_conversation

Create dynamic context from conversation (ML-powered extraction)

{ "name": "conversation-summary", "messages": [ {"role": "user", "content": "..."}, {"role": "assistant", "content": "..."} ], "tags": ["learned-pattern"], "category": "development" }

This automatically extracts: summary, topics, code references, and generates embeddings.

rec_context_enhance

Enhance a static context with ML insights from conversations

{ "contextId": "existing-context-id", "conversationMessages": [...] }

Use Cases

🎨 Code Generation

Generate code that automatically follows your project's coding standards, naming conventions, and architectural patterns. Sora understands your preferences from contexts.

🏗️ Architecture Consistency

Ensure generated code aligns with your system architecture. Sora considers your microservices patterns, API design, and database schemas when generating code.

📚 Learning from Past Work

Convert successful Sora conversations into reusable contexts. Patterns that worked well are automatically learned and applied to future code generation.

🔍 Context Discovery

Use Sora's enhanced search capabilities to discover relevant contexts and patterns. Find best practices faster with semantic search across your knowledge base.

Best Practices

📝 Create Granular Contexts

Create focused contexts for specific areas (e.g., "api-design", "error-handling", "testing-patterns") rather than one large context. This improves relevance and searchability.

🏷️ Use Meaningful Tags

Tag contexts with relevant keywords (e.g., "react", "typescript", "authentication") to improve discoverability and automatic context matching.

🔄 Update from Conversations

Regularly create contexts from successful Sora conversations to capture learned patterns and improve future code generation quality.

🔍 Leverage Hybrid Search

Use RecCall's hybrid search (keyword + semantic) to find relevant contexts quickly. This helps discover related patterns you might have forgotten.

Configuration Options

Environment Variables

# RecCall storage location export RECCALL_STORAGE_PATH="$HOME/.reccall/contexts" # Enable verbose logging for debugging export RECCALL_LOG_LEVEL="debug" # Configure cache TTL (in milliseconds) export RECCALL_CACHE_TTL=3600000 # Enable automatic context creation from conversations export RECCALL_AUTO_CONTEXT=true

MCP Server Options

{ "mcpServers": { "reccall": { "command": "reccall-mcp", "args": [ "--storage-path", "$HOME/.reccall/contexts", "--log-level", "info", "--auto-context" ], "env": { "RECCALL_CACHE_TTL": "3600000", "RECCALL_AUTO_CONTEXT": "true" } } } }

Troubleshooting

MCP Server Not Connecting

Issue: Sora cannot connect to RecCall MCP server.

Solution: Verify RecCall is installed globally and the MCP configuration path is correct. Check Sora logs for connection errors.

Contexts Not Applied

Issue: Generated code doesn't follow your contexts.

Solution: Ensure contexts are tagged correctly and use semantic search to verify context relevance. Check that contexts are being loaded in Sora's MCP tool list.

Performance Issues

Issue: Context loading is slow or timing out.

Solution: Reduce the number of contexts loaded per query. Use filters to limit context scope. Increase cache TTL if contexts don't change frequently.
