Perplexity Integration

Bring persistent context to your Perplexity AI conversations

Overview

RecCall integrates with Perplexity AI to provide persistent context across your conversations. Your project knowledge, coding standards, and architectural decisions are automatically available in every Perplexity interaction.

✨ Key Benefits

  • Persistent Context: Your project knowledge persists across conversations
  • Code Standards: Perplexity understands your coding patterns and preferences
  • Architecture Awareness: AI responses consider your system architecture
  • Team Consistency: Shared contexts ensure uniform AI assistance across team

How to Integrate

1

Install RecCall

First, ensure RecCall is installed globally:

npm install -g reccall

Or use the automated installer:

curl -sfL https://reccaller.ai/install.sh | sh -
2

Configure Perplexity MCP Server

Perplexity supports Model Context Protocol (MCP). Configure RecCall as an MCP server:

{ "mcpServers": { "reccall": { "command": "reccall-mcp", "args": [], "env": {} } } }

Location: Add this configuration to your Perplexity MCP settings file (typically ~/.perplexity/mcp.json or similar based on your Perplexity installation).

3

Create Contexts

Create contexts that will be available in Perplexity conversations:

# Create a static context via CLI reccall context create "react-best-practices" \ --content "Always use TypeScript for React components. Use functional components with hooks. Include PropTypes or TypeScript interfaces. Implement error boundaries." \ --tags react,typescript,best-practices # Or create from a conversation (dynamic context) reccall context from-conversation "react-forms-conversation" \ --messages conversation.json \ --tags react,forms,validation
4

Use in Perplexity

Once configured, your contexts are automatically available in Perplexity conversations:

  • Automatic Context Loading: RecCall automatically injects relevant contexts into Perplexity queries
  • Context-Aware Responses: Perplexity considers your stored contexts when generating responses
  • Search & Discovery: Use Perplexity to search and discover relevant contexts
# In Perplexity, you can ask: "Using my react-best-practices context, show me how to create a form component" # Or: "Search for contexts related to authentication" # Contexts are automatically included based on query relevance

Available MCP Tools

RecCall exposes the following MCP tools to Perplexity:

rec_context_create

Create a new static context

{ "name": "context-name", "content": "Context content", "tags": ["tag1", "tag2"], "category": "development" }

rec_context_get

Retrieve a context by name or ID

{ "identifier": "context-name-or-id" }

rec_context_search

Search contexts using hybrid search (keyword + semantic)

{ "query": "react forms", "limit": 10, "filters": { "tags": ["react"], "category": "development" } }

rec_context_list

List all available contexts with optional filters

{ "filters": { "category": "development", "tags": ["react"] }, "limit": 20 }

rec_context_from_conversation

Create dynamic context from conversation messages (ML-powered)

{ "name": "conversation-context", "messages": [ {"role": "user", "content": "..."}, {"role": "assistant", "content": "..."} ], "tags": ["tag1"], "category": "development" }

Configuration Options

Environment Variables

# RecCall storage location export RECCALL_STORAGE_PATH="$HOME/.reccall/contexts" # Enable verbose logging export RECCALL_LOG_LEVEL="debug" # Configure cache TTL (in milliseconds) export RECCALL_CACHE_TTL=3600000

MCP Server Options

{ "mcpServers": { "reccall": { "command": "reccall-mcp", "args": [ "--storage-path", "$HOME/.reccall/contexts", "--log-level", "info" ], "env": { "RECCALL_CACHE_TTL": "3600000" } } } }

Troubleshooting

MCP Server Not Found

Issue: Perplexity cannot find the RecCall MCP server.

Solution: Ensure RecCall is installed globally (npm install -g reccall) and the path in MCP configuration is correct.

Contexts Not Loading

Issue: Contexts are not appearing in Perplexity conversations.

Solution: Verify contexts exist using reccall context list. Check MCP server logs for errors.

Permission Errors

Issue: Permission denied errors when accessing contexts.

Solution: Check file permissions on ~/.reccall/ directory. Ensure the MCP server process has read/write access.
